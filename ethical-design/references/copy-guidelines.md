# Etička komunikacija i copywriting — Kompletna referenca

Svaki tekst u interfejsu je dizajn odluka. Microcopy može da gradi poverenje ili da manipuliše.
Ovaj dokument definiše pravila za etičko pisanje UI teksta.

---

## Fundamentalno pravilo

**Piši kao da razgovaraš sa pametnijim prijateljem koji ti veruje.**

To znači:
- Poštuj njihovu inteligenciju (ne podcenjuj)
- Poštuj njihovo vreme (budi koncizan)
- Poštuj njihovo poverenje (ne manipuliši)
- Budi direktan (reci šta misliš)

## I. CTA (Call to Action) dugmad

### Pravila:
1. CTA mora jasno reći ŠTA će se desiti kad se klikne
2. Nikad vague formulacije poput "Saznaj više" ili "Klikni ovde"
3. Nikad kreirati lažnu hitnost u CTA tekstu
4. Nikad koristiti manipulativne formulacije

### Primeri po kontekstu:

**Registracija:**
```
❌ "Započni SADA!" (lažna hitnost)
❌ "Ne propusti!" (FOMO)
❌ "Jednom u životu prilika" (preterivanje)

✅ "Kreiraj nalog" (jasno, neutralno)
✅ "Započni besplatan probni period — 14 dana" (konkretan benefit)
✅ "Registruj se — bez kartice" (uklanja strah)
```

**Kupovina/pretplata:**
```
❌ "KUPI ODMAH dok još možeš!" (lažna hitnost + oskudica)
❌ "Da, želim uspeh!" (confirmshaming naspram "Ne" opcije)

✅ "Pretplati se — 29€/mesečno" (jasna akcija + cena)
✅ "Započni sa Pro planom" (neutralno)
✅ "Pridruži se — prvi mesec 50% popusta" (konkretan, realan benefit)
```

**Otkazivanje:**
```
❌ "Odustani od svega" (dramatičan ton)
❌ "Da, želim da izgubim pristup" (confirmshaming)

✅ "Otkaži pretplatu" (neutralno)
✅ "Potvrdi otkazivanje" (jasno)
```

**Newsletter:**
```
❌ "Pridruži se HILJADAMA zadovoljnih čitalaca!" (neprecizno, potencijalno lažno)

✅ "Prijavi se na newsletter — korisni saveti 2x mesečno" (konkretan, iskren)
✅ "Primaš email svake druge nedelje. Odjavi se kad god želiš." (jasan scope)
```

## II. Headlines i naslovi

### Pravila:
1. Budi konkretan, ne senzacionalan
2. Obećaj samo ono što zaista isporučuješ
3. Koristi brojke samo ako su tačne i verifikovane
4. Izbegavaj superlative koji se ne mogu dokazati

### Primeri:

**Landing page headline:**
```
❌ "REVOLUCIONARNI sistem koji će ZAUVEK promeniti tvoj biznis!"
❌ "#1 platforma u Srbiji" (ako nisi verifikovao)
❌ "Tajne uspešnih biznisa koje oni NE ŽELE da znaš"

✅ "Nauči da gradiš web aplikacije uz AI — korak po korak"
✅ "Preko 2.500 korisnika pristupilo platformi u prvoj godini"
✅ "Organski rast na Instagramu za male biznise i kreatore"
```

**Subheadline:**
```
❌ "Pridruži se eliti koja zarađuje dok spava!"

✅ "9 modula, praktični projekti, pristup zajednici i mentoru"
✅ "Od ideje do objavljene aplikacije — bez prethodnog iskustva"
```

## III. Pricing komunikacija

### Pravila:
1. UVEK prikaži punu cenu (sa PDV-om)
2. Jasno naznači period (mesečno / godišnje / jednokratno)
3. Ne koristi "Od..." formulaciju da prikriješ stvarnu cenu
4. Uporedni prikaz planova mora biti pošten

### Primeri:

**Pricing karta:**
```
❌ "Od samo 9€!" (važi samo za godišnji plan sa 10+ korisnika)
❌ Precrtana cena "99€" pored "29€" (ako "99€" nikad nije bila realna cena)
❌ "Najpopularniji!" badge na najskupljem planu (ako nemaš podatke)

✅ "29€/mesečno (uklj. PDV)"
✅ "Godišnji plan: 24€/mesečno — ušteda 17%" (tačan procenat)
✅ "Najpopularniji" badge SAMO ako imaš realne podatke koji to potvrđuju
```

**Uporedna tabela planova:**
```
❌ Free plan sitniji font, manje boja, "gušen" vizuelno
❌ Feature lista gde free plan ima 20 ✗ a premium samo ✓

✅ Svi planovi iste vizuelne težine
✅ Feature lista fokusirana na ono što SVAKI plan NUDI
✅ Jasna razlika BEZ degradiranja jeftinijeg plana
```

## IV. Error poruke i validacija

### Pravila:
1. Nikad ne okrivljuj korisnika
2. Budi konkretan — šta je pošlo po zlu i šta da uradi
3. Ponudi rešenje, ne samo problem
4. Budi human, ne robotski

### Primeri:

```
❌ "Greška! Pogrešan unos."
❌ "Niste pravilno popunili formu."
❌ "Error 422: Unprocessable Entity"

✅ "Email adresa nije u ispravnom formatu. Proveri da li sadrži @ i domen."
✅ "Lozinka mora imati najmanje 8 karaktera. Još ti treba {remaining}."
✅ "Nešto nije u redu sa obradom plaćanja. Proveri podatke kartice ili pokušaj ponovo za minut."
```

**404 stranica:**
```
❌ "Stranica ne postoji." (hladno, nekorisno)

✅ "Ova stranica ne postoji ili je premeštena. Evo gde možeš nastaviti:"
   [Početna] [Blog] [Kontakt]
```

## V. Notifikacije i email-ovi

### Pravila:
1. Svaka notifikacija mora imati JASNU vrednost za korisnika
2. Nikad ne kreiraj anksioznost da bi naterao na akciju
3. Uvek ponudi način da se odjavi ili podesi frekvencija
4. Subject line email-a mora tačno odražavati sadržaj

### Primeri:

**Notifikacije:**
```
❌ "Ne propusti! Tvoji konkurenti napreduju!" (FOMO + strah)
❌ "HITNO: Tvoj nalog zahteva pažnju!" (kad nije hitno)
❌ 🔔 badge sa lažnim brojem nepročitanih

✅ "Nova lekcija dostupna: Uvod u Supabase Auth"
✅ "Tvoja pretplata se obnavlja 15. aprila"
✅ "Imaš 2 nova odgovora u diskusiji"
```

**Email subject lines:**
```
❌ "RE: RE: HITNO!!!" (lažni reply chain)
❌ "Otvori ODMAH — ovo ti menja karijeru"
❌ "Razočaran sam..." (emocionalna manipulacija)

✅ "Nova lekcija: Kako postaviti Auth u 30 minuta"
✅ "Tvoj nedeljni pregled — mart, nedelja 3"
✅ "Podsetnik: pretplata se obnavlja za 3 dana"
```

**Email footer:**
```
✅ Uvek uključi:
   - Zašto korisnik prima ovaj email
   - Jednoklični unsubscribe link
   - Link ka podešavanjima email preferencija
   - Kontakt informacije
```

## VI. Onboarding i forme

### Pravila:
1. Traži SAMO podatke koji su neophodni u tom trenutku
2. Objasni ZAŠTO tražiš svaki podatak
3. Označi koja polja su obavezna, a koja opciona
4. Nikad ne blokiraj napredak nepotrebnim zahtevima

### Primeri:

**Registracija:**
```
❌ Zahtevaj telefon, adresu, datum rođenja za newsletter registraciju

✅ Za newsletter: samo email
✅ Za nalog: email + lozinka (ime opciono)
✅ Za pretplatu: email + lozinka + podaci za plaćanje (u tom koraku)
```

**Progresivno prikupljanje:**
```
✅ Korak 1 (registracija): email + lozinka
✅ Korak 2 (profil, opciono): ime, interesovanja
✅ Korak 3 (kad treba): adresa za fakturisanje
✅ Svaki korak objašnjava zašto traži podatke
```

## VII. Confirmation dijalozi

### Pravila:
1. Obe opcije moraju biti jasno formulisane
2. Obe opcije iste vizuelne težine
3. Neutralan ton bez emocionalne manipulacije
4. Jasno navesti posledice svake opcije

### Primeri:

**Otkazivanje pretplate:**
```
❌
Naslov: "Zaista odlaziš? 😢"
Tekst: "Izgubićeš pristup SVIM lekcijama, zajednici i bonusima!"
Dugmad: [ZADRŽI PRETPLATU (veliko, zeleno)] [odustani (sitno, sivo)]

✅
Naslov: "Otkaži pretplatu"
Tekst: "Pristup ostaje aktivan do 15. aprila 2026.
Možeš se ponovo pretplatiti kad god želiš."
Dugmad: [Zadrži pretplatu] [Potvrdi otkazivanje]
// Oba dugmeta iste veličine, iste vizuelne težine
```

**Brisanje naloga:**
```
✅
Naslov: "Obriši nalog"
Tekst: "Ovo je trajna akcija. Tvoji podaci će biti obrisani u roku od 30 dana.
Ako želiš kopiju svojih podataka, eksportuj ih pre brisanja."
Dugmad: [Eksportuj podatke] [Obriši nalog]
```

## VIII. Social proof i brojke

### Pravila:
1. Koristi SAMO verifikovane brojke
2. Navedi kontekst — za koji period, za koji segment
3. Testimonijali moraju biti realni sa dozvolom korisnika
4. Nikad ne zaokružuj nagore da bi impresionirao

### Primeri:

```
❌ "Hiljade zadovoljnih korisnika!" (neprecizno)
❌ "98% uspešnost!" (bez konteksta)

✅ "Preko 2.500 korisnika pristupilo u prvoj godini" (tačna cifra)
✅ "Prosečna ocena kursa: 4.7/5 (bazirana na 340 recenzija)" (konkretan kontekst)
✅ "87% polaznika završi prvi modul u prvih 7 dana" (merljivo, vremenski okvir)
```

## X. Srpski jezik — specifičnosti

Kad pišeš na srpskom:
- Koristi zarez (",") umesto em crtica ("—") jer je to ispravnije po srpskoj gramatici
- Obraćaj se korisniku sa "ti" (ne "Vi") osim u formalnim kontekstima
- Izbegavaj anglicizme kad postoji dobar srpski ekvivalent
- Koristi ćirilicu ili latinicu konzistentno (ne mešaj u istom interfejsu)
- Lokalizuj formate: datumi (15. april 2026.), valuta (29€ ili 3.400 RSD), telefon
