# Radni rečnik PTS-VK

Ovaj rečnik se proširuje kada se uvede novi alat ili oblast.

## Opšte pravilo

Jedan pojam treba da ima jedan glavni naziv.

Engleski naziv zadrži kada korisnik taj naziv vidi u programu.

## Osnovni termini

| Glavni naziv | Prvo objašnjenje za početnika |
|---|---|
| API | način na koji dve aplikacije razmenjuju podatke |
| API ključ | tajna vrednost koja dozvoljava pristup određenoj usluzi |
| autentifikacija | sistem za registraciju, prijavu i proveru identiteta korisnika |
| autorizacija | pravilo koje određuje šta prijavljeni korisnik sme da uradi |
| baza podataka | mesto gde aplikacija čuva organizovane podatke |
| build | provera i priprema aplikacije za objavljivanje |
| domen | internet adresa aplikacije |
| endpoint | internet adresa preko koje aplikacije šalju ili primaju podatke |
| fajl | pojedinačna jedinica koja sadrži kod ili podešavanja |
| folder | mesto koje sadrži fajlove |
| frontend | deo aplikacije koji korisnik vidi i koristi |
| backend | deo aplikacije koji obrađuje podatke i pravila na serveru |
| Git | sistem koji pamti izmene koda |
| GitHub | internet servis koji čuva Git repozitorijume |
| grana | odvojena linija izmena u Git projektu |
| lokalno | na korisnikovom računaru |
| log | tekstualni zapis događaja i grešaka |
| migracija | kontrolisana promena strukture baze podataka |
| paket | gotov dodatak koji projekat koristi |
| produkcija | javna verzija aplikacije koju koriste stvarni korisnici |
| repozitorijum | projekat sa kodom i istorijom izmena |
| ruta | internet putanja do stranice ili funkcije |
| server | računar ili usluga koja izvršava kod i šalje podatke |
| terminal | prozor za unos tekstualnih komandi |
| webhook | automatska poruka koju jedna usluga šalje drugoj posle događaja |

## Termini za Supabase

| Koristi | Objašnjenje |
|---|---|
| Supabase projekat | jedna odvojena baza i skup Supabase usluga |
| tabela | organizovan skup podataka |
| kolona | vrsta podatka u tabeli |
| red | jedna celina podataka u tabeli |
| RLS pravilo | pravilo koje određuje koje redove korisnik može da vidi ili menja |
| javni ključ | ključ koji može da koristi frontend kada su RLS pravila pravilno podešena |
| servisni ključ | tajni ključ sa visokim pravima koji mora da ostane na serveru |

## Termini za Next.js

| Koristi | Objašnjenje |
|---|---|
| stranica | deo aplikacije koji se otvara na određenoj internet adresi |
| komponenta | deo korisničkog interfejsa koji može ponovo da se koristi |
| server komponenta | komponenta koja se izvršava na serveru |
| klijentska komponenta | komponenta koja se izvršava u pregledaču |
| razvojni server | lokalna verzija aplikacije pokrenuta za rad i proveru |
| promenljiva okruženja | podešavanje koje se čuva van izvornog koda |

## Termini za objavljivanje

| Koristi | Objašnjenje |
|---|---|
| objavi | postavi novu verziju aplikacije na internet |
| hosting | usluga koja pokreće aplikaciju na internetu |
| produkcioni domen | javna internet adresa aplikacije |
| rezervna kopija | sačuvana kopija podataka ili projekta |
| povratak verzije | vraćanje aplikacije na prethodnu ispravnu verziju |
