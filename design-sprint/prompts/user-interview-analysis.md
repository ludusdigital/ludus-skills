# User Interview Analysis Prompt

Analyze interview/test notes.

Separate:
- observed behavior
- direct statement
- interpretation
- pattern
- isolated comment
- usability issue
- desirability issue
- trust issue

Do not treat compliments as validation.

Conclude with:
- evidence for hypothesis
- evidence against hypothesis
- confidence level
- recommended decision: PROCEED / ITERATE / PIVOT / STOP
- next riskiest assumption
