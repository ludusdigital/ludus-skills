# Idea Generation Prompt

Generate multiple fundamentally different solution directions.

Do not produce cosmetic variations of the same UI.

Create:
1. conventional solution
2. simplified solution
3. automation-first solution
4. human-first solution
5. AI-first solution
6. no-interface solution
7. radical solution

For each explain:
- core mechanism
- user flow
- assumption that changes
- main benefit
- main risk
- easiest way to test it
