# Prototype Readiness Checklist

- [ ] Prototip testira jednu primarnu pretpostavku
- [ ] Scope je minimalan
- [ ] Scenario je realističan
- [ ] Entry point je definisan
- [ ] User task je definisan
- [ ] Success signal je definisan
- [ ] Failure signal je definisan
- [ ] Nije izgrađeno ništa što nije potrebno za test
- [ ] Simulirani delovi su dovoljno uverljivi
