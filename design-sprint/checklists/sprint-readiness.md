# Sprint Readiness Checklist

- [ ] Postoji jasan problem ili strateška neizvesnost
- [ ] Poznat je target user
- [ ] Postoji odluka koju sprint treba da informiše
- [ ] Definisan je Long-Term Goal
- [ ] Definisano je Primary Sprint Question
- [ ] Činjenice su odvojene od pretpostavki
- [ ] Identifikovan je deo journey-ja koji se testira
- [ ] Ne pokušavamo da rešimo ceo proizvod odjednom
