# Test Readiness Checklist

- [ ] Testiramo sa relevantnim korisnicima
- [ ] Ne objašnjavamo proizvod unapred
- [ ] Pitanja nisu sugestivna
- [ ] Posmatramo ponašanje, ne samo mišljenje
- [ ] Success threshold je definisan pre testa
- [ ] Beležimo pozitivne i negativne signale
- [ ] Komplimenti se ne računaju kao validacija
- [ ] Znamo koju odluku rezultat testa može promeniti
