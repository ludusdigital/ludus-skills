# Phase 01 — Understand

## Cilj
Razumeti stvarni problem pre generisanja rešenja.

## Pitanja
- Ko je korisnik?
- Koji problem ima?
- Kada se problem javlja?
- Koliko često?
- Kako ga danas rešava?
- Šta ga to košta?
- Šta ga frustrira?
- Koje alternative koristi?
- Koji poslovni rezultat želimo?
- Koja ograničenja postoje?

## Output
- Sprint Challenge
- Target User
- Current Behavior
- Desired Behavior
- Long-Term Goal
- Sprint Questions
