# Design Sprint Skill

AI-native Design Sprint skill za validaciju proizvoda, funkcionalnosti, UX tokova, poslovnih ideja i AI iskustava.

## Glavna ideja

AI je smanjio cenu prototipiranja, ali nije smanjio cenu pogrešne odluke.

Zato skill prioritizuje:

**problem → pretpostavka → eksperiment → dokaz → odluka**

umesto:

**ideja → gradnja**

## Struktura

- `SKILL.md` — glavni operativni dokument
- `principles.md` — principi i anti-patterni
- `workflow.md` — kompletan workflow
- `decision-rules.md` — pravila odlučivanja
- `facilitation-guide.md` — pravila facilitacije
- `phases/` — detalji svake faze
- `templates/` — radni template-i
- `prompts/` — pomoćni specijalizovani promptovi
- `examples/` — primeri upotrebe
- `checklists/` — QA checkliste
